# 🏛️ 대통령 시뮬레이터 2.0

휴대폰에서 플레이하는 **가상 국가 운영 웹게임**입니다. 바가늠공화국의 대통령이 되어 장관을 임명하고, 국정 현안과 외교 위기를 해결하고, 재선에 도전하세요.

## 플레이하기

- **게임 파일:** [index.html](./index.html)
- **공개 웹 주소(배포 설정 완료 후):** https://jiminhong97.github.io/president-simulator/

웹사이트가 아직 열리지 않으면 아래 GitHub Pages 설정을 완료해 주세요.

## GitHub Pages 배포 방법

1. 이 저장소에서 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**를 **Deploy from a branch**로 설정합니다.
3. 브랜치를 **main**, 폴더를 **/ (root)**로 선택하고 **Save**를 누릅니다.
4. Pages 화면에 게시된 주소가 표시되면 휴대폰에서 열어 플레이합니다.

별도 서버, 로그인, API 키, 데이터베이스 설치가 필요하지 않습니다. 로컬에서는 index.html을 브라우저로 열어도 기본 게임을 실행할 수 있습니다.

## 게임 기능

- **랜덤 국정 현안:** 임기당 기본 8턴. 일반 현안 5개, 외교 현안 2개, 비밀 이벤트 1개를 배치하며, 집중호우 선택에 따라 추가 후속 사건이 발생할 수 있습니다.
- **가상 뉴스:** 정책 선택 직후 뉴스, 시민 반응, 지표 변화가 나타납니다.
- **장관 임명:** 경제부 장관, 외교부 장관, 대통령 비서실장을 선택하고 각자의 보너스를 적용합니다.
- **외교:** 무역 협상, 정상회담, 국제 공급망 등의 사건이 포함됩니다.
- **선거와 재선:** 1기 종료 후 게임 내 가상 조건에 따라 재선에 도전하고, 성공하면 2기를 진행합니다.
- **깜짝 이벤트:** 별도의 메시지 입력 없이 비밀 편지 그림을 터치해 메시지를 여는 이벤트가 4번째 턴에 등장합니다.
- **손그림 국기 디자인:** 직접 그린 국기를 그대로 흰 배경과 함께 보존한 이미지로 사용하며 시작 화면, 국정 현안, 뉴스, 선거, 퇴임식에 적용했습니다. 디자인 스타일은 [theme.css](./theme.css), 국기 이미지는 [assets/baganeum-flag.png](./assets/baganeum-flag.png)에 있습니다.
- **자동 저장:** 같은 기기·브라우저·웹 주소에서 저장한 게임을 이어서 플레이할 수 있습니다.

## 저장 관련 주의사항

게임은 브라우저의 localStorage에 저장됩니다. 시크릿 모드 사용이나 브라우저 데이터 삭제 시 기록이 사라질 수 있고, 기기 간 동기화되지 않습니다. 저장이 차단된 브라우저에서는 게임 자체는 실행될 수 있지만 진행 상황이 보존되지 않을 수 있습니다.

## 게임 설정

모든 인물, 국가, 뉴스, 시민 반응, 정책 효과 수치, 재선 성공 조건은 **게임을 위한 가상의 규칙**입니다. 실제 정책의 효과나 선거 결과를 나타내거나 예측하지 않습니다.

## 디자인 변경 전 버전으로 돌아가기

디자인 변경 직전 코드는 [`backup-before-flag-redesign`](https://github.com/jiminhong97/president-simulator/tree/backup-before-flag-redesign) 브랜치에 보관되어 있습니다. 마음에 들지 않으면 이 브랜치의 `index.html`을 `main`에 복원하면 이전 화면으로 돌아갈 수 있습니다. 현재 저장된 게임 데이터를 유지하려면 브라우저 데이터는 삭제하지 마세요.

## 손그림 스토리 업데이트

사용자가 직접 그린 10개 그림을 모바일용 [스토리 스프라이트 이미지](./assets/story-sprite.png)로 모아 적용했습니다. 뉴스에 신문 그림과 시민 표정 3종을 보여주고, 집중호우 선택 결과에 따라 보급 또는 복구 장면이 표시됩니다. 첫 화면과 국정 화면에는 대통령 캐릭터가, 선거 성공·실패 화면에는 별도의 축하/실패 그림이, 비밀 이벤트에는 누르면 열리는 편지 그림이 등장합니다. 그림은 모바일 로딩을 위해 축소한 버전이며 원본 파일은 이 대화에서 제공한 그림들입니다.

이번 업데이트 전 버전은 [`backup-before-story-update`](https://github.com/jiminhong97/president-simulator/tree/backup-before-story-update) 브랜치에 보관되어 있습니다. 기존 브라우저의 게임 저장 기록(localStorage)은 유지됩니다.
