# 🏛️ 대통령 시뮬레이터 2.0

휴대폰에서 플레이하는 **가상 국가 운영 웹게임**입니다. 바가늠공화국의 대통령이 되어 장관을 임명하고, 국정 현안과 외교 위기를 해결하고, 재선에 도전하세요.

## 플레이하기

- **게임 파일:** [index.html](./index.html)
- **공개 웹 주소(배포 설정 완료 후):** https://jiminhong97.github.io/president-simulator/

웹사이트가 아직 열리지 않으면 아래 GitHub Pages 설정을 완료해 주세요.

## GitHub Pages 배포 방법

1. 이 저장소에서 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**를 **Deploy from a branch**로 설정합니다.
3. 브랜치를 **main**, 폴더를 **/ (root)**로 선택하고 **Save**를 누릅니다.
4. Pages 화면에 게시된 주소가 표시되면 휴대폰에서 열어 플레이합니다.

별도 서버, 로그인, API 키, 데이터베이스 설치가 필요하지 않습니다. 로컬에서는 index.html을 브라우저로 열어도 기본 게임을 실행할 수 있습니다.

## 게임 기능

- **랜덤 국정 현안:** 임기당 8턴. 일반 현안 5개, 외교 현안 2개, 맞춤형 비밀 이벤트 1개를 랜덤으로 배치합니다. 비밀 이벤트는 4번째 턴에 등장합니다.
- **가상 뉴스:** 정책 선택 직후 뉴스, 시민 반응, 지표 변화가 나타납니다.
- **장관 임명:** 경제부 장관, 외교부 장관, 대통령 비서실장을 선택하고 각자의 보너스를 적용합니다.
- **외교:** 무역 협상, 정상회담, 국제 공급망 등의 사건이 포함됩니다.
- **선거와 재선:** 1기 종료 후 게임 내 가상 조건에 따라 재선에 도전하고, 성공하면 2기를 진행합니다.
- **깜짝 이벤트:** 별도의 메시지 입력 없이 임기 중 대통령 이름이 포함된 특별한 편지가 등장합니다.
- **자동 저장:** 같은 기기·브라우저·웹 주소에서 저장한 게임을 이어서 플레이할 수 있습니다.

## 저장 관련 주의사항

게임은 브라우저의 localStorage에 저장됩니다. 시크릿 모드 사용이나 브라우저 데이터 삭제 시 기록이 사라질 수 있고, 기기 간 동기화되지 않습니다. 저장이 차단된 브라우저에서는 게임 자체는 실행될 수 있지만 진행 상황이 보존되지 않을 수 있습니다.

## 게임 설정

모든 인물, 국가, 뉴스, 시민 반응, 정책 효과 수치, 재선 성공 조건은 **게임을 위한 가상의 규칙**입니다. 실제 정책의 효과나 선거 결과를 나타내거나 예측하지 않습니다.
