# 🏛️ 바가늠공화국 5.0 — 대통령님! 나라가 이상해요.

휴대폰에서 플레이하는 **완전한 허구의 손그림 병맛 대통령 게임**입니다.
취임 첫날부터 출근을 거부한 대통령이 자신의 선택으로 생긴 황당한 일을 직접 수습합니다.

**플레이:** https://jiminhong97.github.io/president-simulator/

## 5.0에서 새로 만든 것

- **17개 기본 사건과 5개의 후속 사건:** 기본 8턴/임기. 첫 사건은 대통령 출근 거부이며, 3개 선택 중 하나에 따라 낮잠 운동·이불 굿즈·대통령 대역 사건이 발생합니다. 닭나라 독립을 선택하면 닭 정상회담이 뒤따릅니다. 선택에 따라 2차·3차 후속 사건까지 이어집니다.
- **재정과 민심의 쌍방향 관리:** 국고가 늘어나는 굿즈·바자회·수출 등의 선택을 추가했습니다. 국고와 체력 회복 행동은 같은 턴에 종류별로 한 번만 이용할 수 있습니다. 민심·국고·경제·외교·체력·킹받음 지수를 관리합니다.
- **화면별 게임 진행:** 알람 끄기 → 사건 보고 → 대응 선택 → 약 2.8초 결재 연출 → 가상 뉴스 → 후속 사건 또는 새 사건. 뉴스 자동 열기는 스킵할 수 있지만, 읽는 장면은 사용자가 버튼을 눌러야 넘깁니다.
- **미니게임:** 동전 찾기 5회, 토마토 피하기 5회, 대통령 퀴즈 3문항. 성공 횟수에 따라 국고/민심 보너스가 생깁니다.
- **장관/참모:** 취임 첫 사건을 해결한 뒤 경제부 장관과 비서실장을 임명하며, 선택한 특성에 따라 실제 게임 지표 효과가 바뀝니다.
- **가상 선거와 두 번째 임기:** 첫 임기 종료 시 세 가지 게임 속 선거 행동 중 하나를 선택합니다. 내부 게임 규칙을 만족하면 두 번째 임기를 진행할 수 있습니다. 현실 선거 예측이 아닙니다.
- **손그림 디자인:** `assets/doodles/`에 손으로 그린 듯한 선과 흰색 배경을 사용한 **17개 독립 SVG 벡터 그림**을 추가했습니다. 모바일에서 확대해도 픽셀이 뭉개지지 않습니다. 기존 직접 그린 국기·편지·시민 표정 그림은 그대로 재사용합니다.
- **읽기 편한 문장:** 사건 설명은 문장 단위로 별도 문단을 만들며, 한국어 단어 중간의 어색한 줄바꿈을 줄이도록 설정했습니다. 작은 폰에서는 장면 안쪽만 짧게 스크롤합니다.
- **자동 저장:** 같은 기기·브라우저·웹 주소에 5.0 진행 상태를 저장합니다.

## 파일 구조

`index.html`은 5.0 게임 진입점입니다. `game-v5-events.js`에는 사건과 후속 사건, `game-v5-core.js`에는 게임 상태·지표·저장·미니게임·선거 기능, `game-v5-ui.js`에는 모바일 화면과 입력 처리, `game-v5.css`에는 손그림 스타일과 애니메이션을 담았습니다.

## 이전 버전 / 저장 기록 보존

5.0 수정 직전 4.0의 전체 소스는 **[backup-before-bizarre-v5](https://github.com/jiminhong97/president-simulator/tree/backup-before-bizarre-v5)** 브랜치에 보관했습니다. 이전 버전의 소스 파일과 에셋은 그 브랜치에서 확인할 수 있습니다. 마음에 들지 않으면 해당 브랜치의 내용을 다시 `main`에 적용하면 됩니다.

기존 4.0 브라우저 저장 키 `starlight_president_v2`는 **덮어쓰거나 삭제하지 않습니다.** 5.0은 별도의 `baganeum_bizarre_v5` 키를 사용합니다. 다만 4.0의 저장 기록은 게임 구조가 달라서 5.0 상태로 직접 이어서 플레이하지는 못하며, 이전 버전으로 돌아가면 기존 저장 기록을 이용할 수 있습니다(브라우저 저장 데이터를 삭제하지 않은 경우).

## 배포

GitHub 저장소의 **Settings → Pages → Deploy from a branch → main → / (root)** 설정을 사용합니다. GitHub Pages 반영에 잠시 시간이 걸릴 수 있습니다. 기본 HTML/CSS/JavaScript와 로컬 이미지 파일로 구성되어 별도의 서버·로그인·API 키는 필요 없습니다.

> 이 게임에 등장하는 모든 국가·인물·시민 반응·정책 결과·선거는 완전한 허구입니다. 게임 속 지표는 실제 정책 효과나 선거 결과를 설명하거나 예측하지 않습니다.
